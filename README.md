# React Projects

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A collection of small React applications, exercises, and experiments. Each
project is self-contained so it can be installed, run, tested, and built
independently. The repository is useful as a learning workspace and as a set
of focused examples covering React state, forms, TypeScript, styling, APIs,
Next.js, Vite, Bun, and Phaser.

## Why use this repository?

- **Small, focused examples:** Study one concept or application at a time.
- **Several React toolchains:** Compare Create React App, Vite, Next.js, and Bun.
- **Practical interfaces:** Explore job boards, helpdesk tickets, movie
  browsing, investment planning, and password generation.
- **Progressive learning path:** Begin with the introductory exercises and
  move toward TypeScript, persistence, API integration, charts, and games.
- **Independent projects:** Changes and dependencies are scoped to the
  selected directory rather than a monolithic root application.

## Getting started

### Prerequisites

Install a current [Node.js](https://nodejs.org/) release. Use npm for the
Create React App, Vite, Next.js, and Phaser projects. The projects with
`bun.lock` are designed for [Bun](https://bun.sh/), although their manifests
describe the available scripts.

There is no root-level package manifest. Install dependencies from the
directory of the project you want to run.

### Run a project

For an npm-based project:

```bash
cd job-board
npm install
npm start
```

For a Vite project:

```bash
cd PasswordGeneratorApp
npm install
npm run dev
```

For a Bun project:

```bash
cd "Job Management Application Form"
bun install
bun run dev
```

Open the local URL printed by the development server. The exact commands are
defined in each project's `package.json`.

### Movie review app configuration

The [`movie-review-app`](movie-review-app/) requires a TMDB API key. Create a
`.env.local` file in that directory and set:

```dotenv
TMDB_API_KEY=your_tmdb_api_key
```

Then install dependencies and start Next.js:

```bash
cd movie-review-app
npm install
npm run dev
```

Do not commit environment files or API keys.

### Build and check changes

Run commands from the selected project directory. Common commands include:

```bash
npm run build
npm test       # available in the Create React App exercises
npm run lint   # available in Vite and Next.js projects
```

Some projects use `npm start` for development, while Vite, Next.js, and Bun
projects generally use `npm run dev` or `bun run dev`. Check the local
`package.json` before choosing a command.

## Repository layout

Each application keeps its source under `src/`, with framework-specific
configuration, assets, and dependency lockfiles alongside it. The root
contains shared repository metadata and the MIT [`LICENSE`](LICENSE); it does
not coordinate builds across applications.

## Getting help

- Check the selected project's README and `package.json`.
- Consult the official [React documentation](https://react.dev/learn),
  [Vite documentation](https://vite.dev/guide/), [Next.js documentation](https://nextjs.org/docs),
  or [Bun documentation](https://bun.sh/docs).
- Search existing [issues](issues) before opening a new one.
- When reporting a problem, include the project directory, runtime and
  package-manager versions, the command you ran, and the full error output.

## Contributing

Contributions are welcome. To propose a change:

1. Fork the repository and create a focused branch.
2. Make changes only within the relevant project directory when possible.
3. Install that project's dependencies and run its available checks/build.
4. Update its local documentation if behavior or setup changes.
5. Open a pull request describing the project, change, and validation steps.

Please avoid committing `node_modules`, build output, `.env` files, or secrets.
